# Contributing

BYOAg is an experimental open pattern. Contributions should make the concept clearer, improve implementation examples, or sharpen the draft specification without overstating maturity.

## Process

1. Open an issue or proposal with the motivation.
2. Keep changes focused.
3. Run `npm run format`, `npm run lint`, `npm run typecheck`, and `npm run build`.
4. Submit a pull request with a concise summary and validation notes.

## Conceptual Proposals

Conceptual proposals should describe:

- the problem
- the proposed concept
- an example interaction
- trust implications
- unresolved questions

## Content Standards

Use language such as experimental open pattern, draft specification, evolving through implementations and discussion, and open for feedback. Avoid claims of guaranteed compliance, guaranteed interoperability, or formal standard status.
